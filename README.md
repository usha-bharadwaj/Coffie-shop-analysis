# Coffie-shop-analysis
This project analyzes coffee sales data using Excel tools like pivot tables, charts, and formulas to identify trends and performance metrics. It provides insights into top-selling products, seasonal demand, and customer preferences. Ideal for data-driven decision-making and business strategy improvement.

## 📁 File Information

| File Name         | Type       | Description                      |
|------------------|------------|----------------------------------|
| `coffee_dashboard.xlsx` | Excel File | Main interactive dashboard      |
| `README.md`       | Markdown   | Project description & preview    |
| `dashboard-preview.png` | Image      | Screenshot of the dashboard      |

---

## 📌 How to Use

1. Download the `.xlsx` file from this repo.
2. Open in Microsoft Excel (2021 or later recommended).
3. Enable content/macros if prompted.
4. Interact with slicers and dropdowns to explore data.
